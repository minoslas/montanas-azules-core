## 🚀 Instalación y Desarrollo
Este proyecto utiliza políticas estrictas de seguridad de dependencias.

1. Asegúrate de tener Node.js v20 o superior.
2. Instala pnpm: `npm install -g pnpm`
3. Instala las dependencias de forma segura: `pnpm install --ignore-scripts`
4. Ejecuta el simulador: `pnpm run test-logic`
